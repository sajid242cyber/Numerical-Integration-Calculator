## 📌 Project Overview

The **Numerical Integration Calculator** is an interactive web application developed using **Python and Streamlit** as part of the **Numerical Methods** course.

The application is designed to calculate definite integrals using several classical numerical integration techniques. Users can enter a mathematical function, specify the integration limits and number of intervals, select a numerical method, and obtain the approximate integral along with a graphical visualization of the function and integration area.

The project combines **numerical computation, algorithm implementation, mathematical expression handling, data visualization, and interactive web application development** into a single platform.

---

## 🎯 Project Objectives

The major objectives of this project are:

- To implement commonly used numerical integration algorithms.
- To provide an interactive and user-friendly interface for numerical calculations.
- To visualize mathematical functions and their integration regions.
- To validate input requirements for different numerical methods.
- To generate accurate numerical integration results.
- To provide downloadable calculation reports.
- To demonstrate the practical application of Python in Numerical Methods.
- To develop a functional web application using Streamlit.
